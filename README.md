## 🚀 Quick Deploy

### Method 1: Netlify (Easiest!)
```bash
npm install
npm run build
```
Drag `dist` folder to https://app.netlify.com/drop

### Method 2: Vercel
```bash
# Push to GitHub first
git init
git add .
git commit -m "Ultimate game"
git push

# Then import at vercel.com/new
```

### Method 3: GitHub Pages
```bash
npm install gh-pages --save-dev
# Add to package.json: "deploy": "gh-pages -d dist"
npm run deploy
```

## 🎮 Play Guide

**Classic**: Limited tries, get hints  
**Time Attack**: 2 minutes, unlimited rounds  
**Survival**: 3 lives, no try limit  
**Daily**: One attempt per day, global competition  
**Multiplayer**: Race a friend!  

## 💡 Strategy

Use **Binary Search**:
1. Guess middle of range
2. Eliminate half each time
3. Guaranteed optimal!
